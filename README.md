## 📌 Sobre o Projeto

O **MGRUPO** foi idealizado para simplificar a administração de turmas e oferecer uma experiência fluida de aprendizagem para os estudantes. A aplicação é dividida em dois ecossistemas principais:

1. **Painel Administrativo (`/admin`):** Permite aos gestores matricular alunos vincular a um curso específico, gerenciar acessos e publicar conteúdos dinâmicos organizados em **Apostilas em PDF**, **Aulas em Vídeo (YouTube)** e **Simulados Online**.
2. **Portal do Aluno (`/area-logada`):** Área restrita aos alunos matriculados, onde eles visualizam apenas o conteúdo correspondente ao curso no qual estão inscritos.

---

## ✨ Funcionalidades Principais

### 🛡️ **Painel Administrativo**
- **Cadastro de Matrículas:** Inclusão de novos alunos por Nome, E-mail e Seleção do Curso contratado.
- **Controle de PIN:** Acompanhamento do status de ativação da conta do aluno (*Pendente* / *PIN Cadastrado*).
- **Gestão de Materiais de Estudo:** Publicação e exclusão de materiais por categoria:
  - 📄 **1. Apostilas em PDF** (Links do Google Drive, Dropbox, etc.)
  - 🎥 **2. Vídeos / Aulas** (Links diretos do YouTube)
  - 📝 **3. Simulados Online** (Links de formulários ou plataformas interativas)
- **Filtro por Curso:** Cada material publicado é associado diretamente ao curso correspondente.

### 📚 **Portal do Aluno**
- **Autenticação Segura:** Login via e-mail e PIN cadastrado.
- **Ambiente Personalizado:** Exibição do nome, e-mail e status da matrícula.
- **Conteúdo Filtrado:** O aluno enxerga exclusivamente as Apostilas, Vídeos e Simulados vinculados ao seu curso.
- **Acesso Rápido:** Links diretos para abertura de PDFs, aulas no YouTube e realização de simulados em uma interface responsiva.

## 🗄️ Estrutura do Banco de Dados (Supabase)

O projeto utiliza duas tabelas principais no PostgreSQL gerenciadas pelo Supabase:

### 1. Tabela `alunos_matriculados`
```sql
CREATE TABLE IF NOT EXISTS alunos_matriculados (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  nome VARCHAR NOT NULL,
  email VARCHAR NOT NULL UNIQUE,
  curso VARCHAR NOT NULL DEFAULT 'TÉCNICO EM ENFERMAGEM (SES)',
  pin_cadastrado BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);
